# Complete encoding/json v0.2 measurement

All eight active production files from Go 1.26.3 `encoding/json` are included:
4,264 normalized Go lines. Tests, dependencies and inactive build variants are
excluded. File selection is fixed before measuring. The Go and Smol bundles use
identical filename markers.

The code channel retains identifiers, literals and directives. Comments and
blank lines are stored separately in `package.notes.txt` and are not included
in the code-channel request.

| Input | Whole request tokens | Source tokens above empty baseline |
|---|---:|---:|
| Empty baseline | 14,469 | — |
| Go | 47,378 | 32,909 |
| Smol v0.2 code | 30,846 | 16,377 |

The three preserved `gpt-6.1-sol` repetitions are identical: **50.235% source
reduction**, **34.894% whole-request reduction**, saving 16,532 tokens. Compared
with [v0.1](../encoding-json-v0.1/), the code channel saves another 12,521 tokens,
or 43.328%.

The 2026-11-15 audit freshly rebuilt the translator and regenerated byte-identical
Go, code, notes and outline bundles. It verified payload hashes, every raw usage
event and local `o200k_base` counts; no fresh API requests were made.
[Current audit](../../VALIDATION.md) ·
[Verification and uplift](../spec-v0.2-validation/uplift.json).

Code and notes together cost 34,093 tokens, 3.598% more than Go. The gain applies
to code-only model context. Outlines are read-only partial views, and their
known conformance defects are recorded in the audit. No coding-accuracy or
latency claim is made.

Reproduce into a fresh output directory:

```sh
go build -o bin/smol ./cmd/smol
python3 scripts/prepare_package.py encoding/json \
  --output measurements/spec-v0.2-validation/encoding-json
python3 scripts/validate_lowered.py
python3 scripts/measure_uplift.py
```

For new API usage, run `scripts/measure_usage.py` with explicit `--go`,
`--smol`, `--model` and a new `--output` directory. Preserve the original evidence.
